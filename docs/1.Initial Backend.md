
# Setup Express Backend

## 1. Initalize node.js
### create a package.json
```zsh
npm init -y
```
It skips the questions and creates a package.json with default values

### 2. Install Express (creates node_modules)
```zsh
npm install express@4.18.2
```
Downloads Express and saves it into your project’s `node_modules` folder
- Easy routing
- Middleware Support
- Send JSON Easily

### 3. Create server.js
Creating a server.js file as the entry point is actually just a convention, not a strict rule.

## 4.Enable ES module -backend/package.json
```json
 "type": "module", 
```

Enable ES module support
- Enabled in Node.js when you set "type": "module" in package.json
- Uses import and export. `import express from "express";`

## 5. Add scripts -backend/package.json
```json
  "scripts": {
    "dev": "node server.js"
  }
```
- Add scripts, when use terminal run `npm run dev` is same as `node server.js`

## 6. Create Server - server.js
create first router
```js
import express from "express";

const app = express();

app.get("/api/notes", (req,res) => {
    res.status(200).send("you got 5 notes")
})

app.listen(5001, () => {
    console.log("Server started on PORT:5001")
});
```

```zsh
npm run dev
```


> **Q: Can we get rid of API?**  
**A:** No. If your frontend (React, mobile app) needs to talk to the backend, you must have some kind of API. Otherwise, the frontend would have no way to request data or send updates.

👉 The API is the **contract** between client and server.
