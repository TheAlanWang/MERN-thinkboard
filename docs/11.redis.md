# Redis
```
├─ src/
│  ├─ config
│  │  └─ upstash.js             # Responsible for connecting to Redis
│  ├─ middleware
│  │  └─ rateLimiter.js         # Rate limiting logic
│  └─ server.js                 # Add middleware function
```
### set .env
```zsh
UPSTASH_REDIS_REST_URL="https://h.upstash.io...."
UPSTASH_REDIS_REST_TOKEN="Adrc..."
```

### install
```zsh
npm install @upstash/ratelimit@2.0.5 @upstash/redis@1.34.9
```

### src/config/upstach.js
```js
import { Redis } from "@upstash/redis";
import { Ratelimit } from "@upstash/ratelimit";

import dotenv from "dotenv";
dotenv.config(); 

// create  a ratelimit instance
const ratelimit = new Ratelimit({
  redis: Redis.fromEnv(),
  limiter: Ratelimit.slidingWindow(10, "20 s"),
  analytics: true,
});

export default ratelimit;
```

### -src/server.js
```js
connectDB();

app.use(express.json()); // Middleware to parse JSON request bodies
app.use(ratelimit); // Apply rate limiting middleware
```

### -src/middleware/rateLimiter.js
```js
import ratelimit from "../config/upstash.js";

const rateLimiter = async (req, res, next) => {
  try {
    const { success } = await ratelimit.limit("my-limit-key")

    if (!success) {
      return res.status(429).json({
        message: "Too many requests, please try again later."
      });
    }
    next(); // Proceed to the next middleware or route handler
  
} catch (error) {
    console.log("Rate limiting error:", error);
    next(error);
  }
};

export default rateLimiter;
```
"my-limit-key" is hardcoded.:It means all requests (no matter who/where from) share the same bucket, so rate limiting applies globally across the whole app.
