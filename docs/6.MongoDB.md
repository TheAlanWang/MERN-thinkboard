# MongoDB

## SQL vs NoSQL
| Feature              | SQL (Relational DB, e.g., PostgreSQL) | NoSQL (Non-Relational DB, e.g., MongoDB)  |
|----------------------|----------------------------------------|------------------------------------------|
| **Data Model**       | Tables with rows and columns           | JSON-like documents, key-value, graph, wide-column |
| **Query Language**   | SQL (`SELECT`, `INSERT`, `JOIN`, etc.) | Varies (MongoDB uses JSON-like syntax)   |
| **Best for**         | Bank, Social Media - account           | Big data, real-time apps                 |
| **Schema**           | Fixed, structured schema               | Flexible, dynamic schema                 |
| **Consistency**      | Strong consistency (ACID transactions) | Eventual consistency (depending on DB)   |
| **Scalability**      | Vertical scaling (bigger server)       | Horizontal scaling (add more servers)    |
