# Tailwind
Tailwind CSS is a utility-first CSS framework.
Instead of writing your own CSS rules in a .css file, you directly use small, pre-defined CSS classes in your HTML/JSX.

[Install Tailwind CSS with Vite](https://v3.tailwindcss.com/docs/guides/vite)


## Install tailwind
```zsh
npm install -D tailwindcss@3 postcss autoprefixer
npx tailwindcss init -p
```

creates two files at the root of the project
```
frontend
├─ postcss.config.js   ← created by `npx tailwindcss init -p`
├─ tailwind.config.js  ← created by `npx tailwindcss init -p`
├─ src/
│  ├─ index.css        ← add Tailwind directives here (@tailwind base; etc.)
```

## replace tailwind.config.js by documentation
```js
/** @type {import('tailwindcss').Config} */
export default {
  content: [
    "./index.html",
    "./src/**/*.{js,ts,jsx,tsx}",
  ],
  theme: {
    extend: {},
  },
  plugins: [],
}
```

-frontend/src/index.css
```css
@tailwind base;
@tailwind components;
@tailwind utilities;
```
