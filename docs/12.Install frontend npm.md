# Vite
frontend build tool
- In dev, use ESM, browser loads fils on demond. startup and hot updates extremely fast.
- In prod, rollup to bundle and optimize everything into efficient static assess

## Install Summary:
- npm create vite         → super fast startup in development
- npm i react-router      → official routing library for React.
- npm i react-hot-toast   → give app user-friendly feedback messages

## install vite -/frontend
```zsh
npm create vite@latest .
```
```
frontend
├─ index.html        → load first, connect to react starts from `main.jsx`
├─ vite.config.js    # Vite configuration file
├─ package.json      # Project dependencies & scripts
├─ node_modules/     # Installed dependencies
├─ public/           # Static files (not processed by Vite)
└─ src/              # Source code folder
   ├─ main.jsx       # React entry file
   ├─ App.jsx        # Main App component
   ├─ assets/        # Default images (can delete)
   └─ index.css      # Global styles

```
choose react + javascript

```zsh
npm install
npm run dev
```

### Set frontend/main.jsx
In a Vite + React project, main.jsx is auto-created by Vite as the app’s entry file.
To use React Router, need to import and wrap <App /> with <BrowserRouter> in main.jsx. 

```jsx
import { BrowserRouter } from 'react-router-dom'

createRoot(document.getElementById('root')).render(
  <StrictMode>
  <BrowserRouter>
    <App />
  </BrowserRouter>
  </StrictMode>,
)
```
