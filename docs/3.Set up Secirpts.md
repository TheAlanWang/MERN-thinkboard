# Set up scripts for dev (nodemon) and production (node)
## Auto-restart on file changes
To auto restarts your Node.js server whenever you save changes, install nodemon.
```zsh
backend % npm install nodemon -D
```
-D / --save-dev → save this dependency in the "devDependencies" section of your package.json

Auto add in package.json
```
  "devDependencies": {
    "nodemon": "^3.1.10"
  }
```

Manually edit backend/package.json
```js
 "scripts": {
    "dev": "nodemon server.js"
  },
```

## add production start
Manually edit backend/package.json, means:
- development: autp restart on save
- production: plain Node.js
```js
 "scripts": {
    "dev": "nodemon server.js",
    "start": "node server.js"
  },
```
