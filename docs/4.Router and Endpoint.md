# Router and Endpoint

## Router & Endpoint
Router: organizes related routes/endpoints into groups
Endpoint: a specific URL + HTTP method combination that the client can call.

Example:
```js
// router
router.get("/api/user", (req, res) => {res.send("Get all notes");});
// endpoint
GET /api/user
```

## define Rest Api routes in Express framework
```js
app.get("/api/notes", (req, res) => {
    res.status(200).send("API is running successfully!!!");
});

app.post("/api/notes",(req,res) => {
    res.status(201).json({message: "post send successfully"})
});

app.put("/api/notes/:id",(req,res) => {
    res.status(201).json({message: "post update successfully"})
});

app.delete("/api/notes/:id",(req,res) => {
    res.status(201).json({message: "Note delete successfully"})
});
```

## Router modularization
```zsh
routes/
 ├─ notesRoutes.js   → handles /api/notes endpoints
 ├─ usersRoutes.js   → handles /api/users endpoints
 └─ authRoutes.js    → handles /api/auth endpoints
```

### /backend/server.js
```js
import notesRoutes from "./routes/notesRoutes.js";

app.use("/api/notes", notesRoutes)
```
app.use:
- app → your Express application object.
- use() → is used to register middleware or routes.

It means: when the request path matches, pass the request to the specified route handler (notesRoutes).

### backend/routes/notesRoutes.js
```js
import express from "express";

const router = express.Router(); // const app = express();

router.get("/", (req, res) => {
    res.status(200).send("You just fetched the notes");
});

router.post("/", (req, res) => {
    res.status(201).json({message: "Note created successfully"});
});

router.put("/:id", (req, res) => {
    res.status(200).json({message: "Note updated successfully"});
});

router.delete("/:id", (req, res) => {
    res.status(200).json({message: "Note deleted successfully"});
});

export default router; // make `routers` available outside the file
```
`const router = express.Router();`
- Create a new Router object from Express
- Think of this as a "mini Express app" that can handle its own routes and middleware.
- We use it to organize related routes in a separate file instead of cluttering app.js.
const router = express.Router();
