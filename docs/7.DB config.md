## Add .ignore .env
1. Install dotenv
```zsh
npm install dotenv 
```
2. Create a .env file (at project root, same place as package.json)
3. Load .env in server.js (or app.js)
```js
import dotenv from "dotenv";
dotenv.config();
dotenv.config({ quiet: true }); //dotenv not to print any log

const PORT = process.env.PORT || 5001; //If process.env.PORT is not set (undefined), then PORT = 5001.
process.env.MONGO_URI
```
